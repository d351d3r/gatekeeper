# Optional assets (not required to build)

Source PNGs for the freeze/unfreeze icons:

| File | Used for |
|------|----------|
| `gatekeeper_icon_freeze_source.png` | freeze icons |
| `gatekeeper_icon_unfreeze_source.png` | unfreeze icons |

Generated icons are committed under `app/src/main/res`:

- `ic_toolbar_*` — transparent background (toolbar, snowflake badge in app list)
- `ic_shortcut_*` — opaque `#223D2C` PNG for API 25 and older launchers
