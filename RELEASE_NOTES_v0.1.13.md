## Gatekeeper 0.1.13 (22)

- Сборка под Android 17 (API 37): устаревшие API заменены, разрешение фонового запуска для PendingIntent задано явно.
- Биндеры служб Gatekeeper выполняют методы только для самого Gatekeeper; рабочая служба доказывает общий ключ до того, как личная сторона ей доверится, а сам ключ больше не уходит в каждом служебном интенте.
- Приложения, объявившие служебные действия Gatekeeper, обнаруживаются: главный экран предупреждает о них и предлагает заморозить.
- Набор политик изоляции, который уходит в рабочий профиль, теперь подписан: подделка, перехватившая служебный интент, не может переписать его и выключить изоляцию.
- Публичная разморозка из рабочего профиля больше не принимается; статус установщика принимается только от собственного системного колбэка.
- Новая политика изоляции «Ссылки из профиля открывать только в профиле» (входит в пресет «Изолированный»): ссылка из приложения профиля не уходит в личный браузер, через ваш VPN и с личными cookie.
- Запреты установки и удаления из экрана изоляции больше не снимаются молча: Gatekeeper снимает их только на время собственной установки и сразу возвращает.
- Политики рабочего профиля применяются заново только при изменении настроек, после обновления, переустановки или перезагрузки, а не на каждом переходе между профилями.
- Отмена диалогов неизвестных источников и MIUI корректно завершает операцию; сбой открытия сессии установки и пустой ответ на запрос разрешения больше не роняют приложение.
- Определение VPN: сбой одного сигнала больше не отключает остальные.
- Перенос медиа: фото с расширением в верхнем регистре (IMG_0001.JPG) распознаются на Android 7–9; нулевой размер миниатюры больше не зацикливает декодирование.
- Закрепление и снятие ярлыков разморозки больше не делают вызовы в систему с главного потока; вытеснение VPN не теряет сигналы и не ждет лишнюю секунду на регистрации получателя.
- Сборка: Gradle 9.8.2, Android Gradle Plugin 9.5.0, Kotlin 2.4.21, Java 17, AndroidX Fragment 1.9.1.
